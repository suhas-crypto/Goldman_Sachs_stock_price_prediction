# Goldman_Sachs_stock_price_prediction
Predicts Goldman Sachs stock prices using a multi-model ML pipeline (ARIMA · Prophet · XGBoost · LSTM). Served via FastAPI, tracked with MLflow, and deployed on AWS EC2 with Docker Compose. Stack: Python · PyTorch · Scikit-learn · FastAPI · MLflow · Docker · AWS EC2 · Nginx · Gunicorn
